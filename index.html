TravelOps AI Agent

Oct 2026 · live on Render

Turns a travel customer's free-text enquiry into a priced, validated quotation for human approval. An LLM extracts requirements into a strict schema, RAG retrieves hotels, transport, activities and policies, the agent calls seven allow-listed tools and proposes inventory codes, and deterministic Python prices every line and checks it against the budget. Every run is stored as an inspectable trace: tools, arguments, retrieved chunks, tokens and cost.

34eval cases
63offline tests
100%price accuracy
64%tool selection

The 64% is real: the model sometimes skipped the transport search on live runs. It's documented in the README rather than hidden, with the three bugs that only appeared against real APIs and the regression test each one got.
